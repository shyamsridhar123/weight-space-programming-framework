# Generic study results and interpretation

The completed study shows a reproducible **target-change versus retention tradeoff** across three explicitly implemented model families. Soft retention lowers collateral drift substantially compared with target-only fitting, while sacrificing target accuracy. Numerical anchor protection, finite precision, and repeated edits introduce distinct limits. Exact parameter reconstruction and real-valued theorems help make those limits inspectable; neither substitutes for useful behavior on an intended task population.

This is a deterministic, fitting-permitted synthetic study. It does not evaluate a live language model, independently replicate the original report, or establish large-model or real-world gains. The [source review](source-review.md), [methods](methods.md), [formal guide](formal.md), and [limitations and next steps](limitations-and-next-steps.md) supply those boundaries in detail.

## What the errors measure

The target request adds \(s=(0.6,-0.3,0)\) to the original checkpoint's output when \(x_0>0.35\). Retention asks for unchanged original output when \(x_0<-0.1\). The intervening region is not measured by this main task. Both main metrics use the requested-shift RMS, \(\sqrt{0.15}\), as their denominator:

\[
E_T=\frac{\operatorname{RMS}(f_{\mathrm{edit}}(x)-f_{\mathrm{base}}(x)-s)}{\operatorname{RMS}(s)},\qquad
E_R=\frac{\operatorname{RMS}(f_{\mathrm{edit}}(x)-f_{\mathrm{base}}(x))}{\operatorname{RMS}(s)}.
\]

The first is evaluated on target inputs and the second on retention inputs. Lower is better for both. The no-op has target error one and retention error zero. These are score-space errors, not classification accuracy, reward, or probabilities. Directional gain is a separate projection onto the requested shift; it is not generally one minus target NRMSE. Teacher-relative task errors are reported separately below.

## Six fixed arms

Each arm has 36 held-out checkpoint outcomes. These descriptive means weight all three families equally because every world completed every family.

| No-op | 1.000000 | 0.000000 | 0.000000 | 0.000000 |
| Unconstrained target fit | 0.038695 | 0.888351 | 0.989872 | 0.569264 |
| Soft retention | 0.360218 | 0.199321 | 0.700712 | 0.978042 |
| Numerical nullspace, 12 anchors | 0.343031 | 0.338563 | 0.834693 | 1.334016 |
| Matched random | 1.210108 | 0.682883 | 0.001962 | 0.978042 |
| Gradient, 200 steps | 0.383597 | 0.185988 | 0.663043 | 0.655744 |

The target-only fit nearly realizes the requested shift but spreads a large change into the retained region. Soft retention gives up target accuracy to reduce that spread. The numerical-nullspace arm has better mean target error than soft retention but worse mean unseen retention; protecting 12 supplied anchors is a different objective from penalizing all public retention rows.

The matched-random direction has the same requested support and L2 as the realized soft endpoint delta. Its mean realized L2 matches to the displayed precision. Its poor target result indicates that direction matters in this fixture. There is only one random direction per checkpoint, so this is not a characterization of the entire random-edit distribution or a complete causal-mechanism test.

The gradient arm optimizes the same soft objective for a fixed 200 steps. It has slightly worse target error and lower collateral drift than the direct soft fit. Different endpoints on this tradeoff do not establish that the compiler dominates optimization. The study does not tune competing optimizers, match total computation, or compare end-to-end fine-tuning.

## Native precision and realized changes

Each precision condition first projects its own parent model to the declared format. The compiler extracts binary64-lifted features from that parent, fits the soft edit, and projects the candidate. CPU PyTorch executes the native parent and candidate on the saved test inputs. The comparison therefore measures execution and endpoint differences for each format's own parent, not the effect of only changing the output dtype of one identical model.

| Format | Checkpoints | Native target NRMSE | Native retention NRMSE | Maximum native-versus-lifted edit-drift discrepancy | Rounded endpoint cells | Requested / effective changed cells |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Float64 | 36 | 0.360218 | 0.199321 | 1.554e-15 | 0 | 2520 / 2520 |
| Float32 | 36 | 0.360218 | 0.199321 | 4.337e-07 | 2520 | 2520 / 2520 |
| Float16 | 36 | 0.360231 | 0.199307 | 1.287e-03 | 2520 | 2520 / 2520 |
| Bfloat16 | 36 | 0.360280 | 0.199336 | 1.034e-02 | 2520 | 2520 / 2512 |

Cell counts are sums across checkpoints. Rounded endpoint cells count requested edit endpoints that change during projection, excluding the initial projection of each parent model. Rounding is measured against the requested binary64 endpoint; a rounded cell can still count as an effective change. Eight requested bfloat16 changes disappear. The maximum discrepancy is over saved test outputs and checkpoints, not a population-wide or worst-case input bound.

![Measured native arithmetic discrepancy](../../../artifacts/weight-space/study-v2-report-complete/native-precision.png)

Aggregate target and retention errors change little in these small fixtures, while the maximum execution discrepancy grows with lower precision. This is evidence for recording both endpoint realization and actual execution. It does not justify ignoring rounding in other models, near decision boundaries, on GPUs, or under different operation orders. No IEEE-execution theorem is supplied, even for float64.

## Three-edit sequences and interference

For every checkpoint, both complete three-edit chains were constructed and sealed before sequence test evaluation. The three target regions are \(x_0<-0.5\), \(|x_0|<0.2\), and \(x_0>0.5\), with different requested output shifts. At each stage the target remains the original model plus that region's prescribed shift; soft retention penalizes changes to the current model in the other regions. This strategy is not a cumulative contract against the original model.

| Family | Method | Chains | Final mean target NRMSE | Final prior-region interference NRMSE | Exact compositions | Exact rollbacks |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| ReLU MLP | Target-only | 12 | 1.178485 | 1.715786 | 12 | 12 |
| ReLU MLP | Soft retention | 12 | 0.853399 | 0.304080 | 12 | 12 |
| Tanh MLP | Target-only | 12 | 1.124716 | 1.642258 | 12 | 12 |
| Tanh MLP | Soft retention | 12 | 0.784631 | 0.285124 | 12 | 12 |
| Convolution + tanh | Target-only | 12 | 0.976328 | 1.400464 | 12 | 12 |
| Convolution + tanh | Soft retention | 12 | 0.753396 | 0.333682 | 12 | 12 |

Prior-region interference compares the final outputs with each earlier region's outputs immediately after its own edit, normalized by that region's prescribed-shift RMS. It measures erosion from a previously reached state, not how close that state was to the desired behavior. Final target error measures the latter separately. The [methods](methods.md) give the complete definitions.

![Per-stage desired-behavior error for every region and method](../../../artifacts/weight-space/study-v2-report-complete/sequential-interference.png)

Before a region is targeted, its desired behavior is the unchanged baseline. The heatmap uses each region's own prescribed-shift RMS throughout. Target-only edits acquire the newest shift accurately but strongly disrupt prior regions. Soft retention substantially reduces interference, yet its second region's final mean desired-behavior error exceeds one in every family, approximately 1.14–1.16. Lower interference alone is therefore not evidence that all requested tasks were successfully acquired and retained.

Every one of the 72 chains composes to the same final parameter identity as sequential application, and every rollback restores the original artifact identity. These structural results remain true despite imperfect behavior. Literal rollback restores stored parameters; it cannot reverse prior deployed actions, external state, or random trajectories. Three fixed edits and one task order do not establish long-horizon retention, additive improvement, or absence of forgetting.

## Reading, diagnosis, and creation controls

The auxiliary suite completes six cases per world, 72 total. Four cases are read/diagnose sign fixtures under exact or three-decimal access; two are analytic creation fixtures. The hidden response evaluation uses 128 examples per case. These cases are separate task routes, not an additional large-model benchmark or a pooled accuracy measure.

| Read/diagnose access | Cases | Correct sign | Incorrect sign | Abstentions | Exact response arrays | Maximum response error |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Exact | 24 | 24 | 0 | 0 | 24 | 0 |
| Rounded to three decimals | 24 | 0 | 0 | 24 | 0 | 7.998e-04 |

The designated coefficient has magnitude 0.0004. Three-decimal access displays `0.0` or `-0.0`; the interface preserves the sign bit. The task prescribes abstention at displayed zero, and the fixed reader follows that rule without using the sign bit. Exact access yields the correct sign. This is a fixed-policy abstention control, not evidence that rounding makes sign information unrecoverable. The positive read and negative diagnosis fixtures are simple routing controls; they do not establish that the framework discovers unknown mechanisms. An abstention is retained as an abstention, not silently counted as an incorrect guess or a successful identification.

The creation cases compare zero, one seeded random artifact, and a preselected analytic construction for each supplied formula. The numerical tolerance is \(10^{-12}\).

## Teacher-relative errors and real-valued domain bounds

Editing is defined against the checkpoint's outputs, while the synthetic teacher supplies an independent task reference. The original checkpoints' mean target-region RMSE against the unshifted teacher is 0.249446, and retained-region RMSE is 0.247854. The desired edited teacher adds the target shift in the target region.

| Arm | RMSE against shifted teacher on target | RMSE against unchanged teacher on retention |
| --- | ---: | ---: |
| No-op | 0.470232 | 0.247854 |
| Target-only | 0.250060 | 0.432415 |
| Soft retention | 0.288673 | 0.264259 |
| Nullspace, 12 anchors | 0.284989 | 0.287193 |
| Matched random | 0.549483 | 0.385287 |
| Gradient | 0.293504 | 0.262675 |

These values are raw output RMSE, not the normalized edit metrics. A faithful edit can retain the original model's approximation error; preserving the parent is not equivalent to recovering the teacher. No-op's shifted-target error should not be confused with the original checkpoint's error against the unshifted teacher.

The ReLU soft-retention candidates also have exact-rational sequential drift receipts on the whole input box. Across the 12 checkpoints, the first-output bound ranges from **5.570890 to 8.295392**, the second from **2.785445 to 4.147696**, and the third is zero. These full-box bounds include the intended target effect and discard cancellation. They are conservative and cannot be substituted for a tight retention-region bound merely because the measured retention error is low.

The runtime receipts evaluate a real-valued recurrence. The separate Lean theorem proves that recurrence under its mathematical premises, but these new JSON endpoints are not automatically generated as checked Lean instances. There is no corresponding all-layer tanh or convolution proof in this study. Generic head residuals for those fixtures concern supplied lifted features, not a proof of their extractor or native execution.

## Conclusions that follow, and experiments still needed

The evidence supports the following bounded conclusions. One common artifact and workflow layer can run explicit non-RTS task families and architectures. The fixed retention-aware algorithms expose an observable target/collateral tradeoff. Anchor count, exact realized residuals, dtype projection, and task sequence materially affect what a valid edit means. Parameter composition and rollback can be checked independently of behavioral success. The new theorems clarify conditional preservation and infeasibility rather than declaring every proposed change useful.

The remaining claims need different evidence: unseen feature-domain coverage needs representation witnesses or bounded residuals; generic behavioral admission needs an integrated contract; runtime proof binding and native error need further correspondence work; live weight understanding needs context-matched access experiments; causal repair needs directional intervention controls; repeated usefulness needs cumulative contracts, new task orders, and longer sequences; and scale needs complete resource measurements. The [prioritized program](limitations-and-next-steps.md) gives concrete designs and falsification criteria for each.

All seeds in this study are now observed. A fresh confirmation must freeze new units and its analysis before observation. The old first-study regression estimates remain conditional on their shared dataset, and the historical RTS result remains a selected no-op with zero held-out effect. This broader generic study does not retroactively change either result or repair missing historical checkpoint bodies. See the [version-one results](../results.md) and [project memory](../../PROJECT_MEMORY.md) for their original scope.
