A #17 canonical payload hash serializes the whole top-level JSON object after removing only its top-level `sha256`, with sorted keys, compact separators, UTF-8, `ensure_ascii=False` and `allow_nan=False`. Full canonical JSON includes that existing field. Parsing rejects duplicate keys and nonfinite numbers. Original inventory digests and sanitized inventory digests identify different objects. Each JSON derivative has its own canonical payload self-hash; none inherits the original's identity.

Sanitization uses explicit recursive field/type whitelists. It replaces machine locators with documented roles or repository-relative paths and omits PIDs, environment-variable values and raw provider event/diagnostic/stderr contents.
