What you are programming

A small authored, untrained auxiliary game policy. Editing W₂[19] changes a numeric parameter that scores available orders. This demonstration uses no online gradient training.

What Laya contributes

Laya suggests a bounded numerical change for review. Its own checkpoint stays fixed. The attack-bias proposal shown in the film is left unapplied.

What the result means

The paired experiment shows a recruitment/economy trade-off. The later victory is a separate manual playthrough. It does not establish that the edited policy is a better strategist.
