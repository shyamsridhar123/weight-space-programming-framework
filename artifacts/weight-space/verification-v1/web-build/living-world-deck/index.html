A living world. A visible mind.

This interactive deck needs its small local server so that video seeking, the experiments, and the audience window work together.

On Windows, double-click start-deck.cmd, then open the address printed in its window.

On any platform with Node.js 22 or newer, open a terminal in this folder and run node serve.mjs. Open http://127.0.0.1:4180/ in your browser and keep the terminal open.
