# Attribution and rights

This repository is a private research draft. No project-wide software or document license grant has been selected for the framework. Absence of a license does not create an open-source permission grant.

The framework was assembled from the weight-space programming work in the RLCD workspace. Its import namespace remains `rlcd.weight_space` so the code and frozen source identities remain inspectable. The standalone packaging, image diagrams, navigation, and publication records are documented in the changelog and publication manifest.

The original author report, **Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights** (November 2, 2026), and its released experiment repository are external source material. The [source review](docs/weight-space/v2/source-review.md) identifies authors, source URLs, dates, claims, limitations, and acquisition scope. The [retained source archive](artifacts/weight-space/source-review-v2/README.md) includes upstream notices and the licenses supplied with those files, including the retained repository license and MinAtar license.

Upstream material retains its existing ownership, notices, and license conditions. This repository does not relicense those materials or imply that the original authors endorse this framework. Mathematical and empirical claims should be attributed to their actual source, with this framework's extensions and synthetic study identified separately.

Before a public release, the maintainer must choose a license for material they can license and review the redistribution terms of retained third-party material. The current draft preserves attribution rather than applying a blanket license across the evidence archive.
