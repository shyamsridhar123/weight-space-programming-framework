# Enterprise routing demo

This local demonstration explains the generic Weight Space Programming Framework
through a synthetic support-routing policy change. Its audience is an enterprise
technical decision maker exploring how a targeted weight edit is specified,
checked, selected, evaluated, and reversed.

The user requested a nice, simple interface and a real screen recording that
highlights the framework's core concepts, this enterprise use case, and impact.
Use a quiet, light interface with a guided, readable walkthrough. Keep the
business decision first and make the underlying evidence inspectable.

The supplied structured-field extractor and hand-constructed linear head are
synthetic. They are not a trained text classifier. The observed outcome is a
General Support to Platform Operations routing change with zero sampled
protected score drift. Conflict causes abstention; a symptom coverage gap
causes rejection after final evaluation. Potential operational value must be
separated from measured outcomes. No savings or production performance is known.

Use the repository's actual Python example and receipts. All controls work
locally without external providers, keys, or customer data. No Mermaid.
Rollback restores model tensors and metadata, not existing ticket assignments.
The framework remains generic; this route is one application.
