# Original actor conversions and adapted repetition

The actor values under [converted](../../experiments/research/original-source-repeat/converted/) are adaptations of the experiment 1 networks released in `RikiyaT/lm_understand-logs` at commit `4d09ba6d6a7e891dd8063974dfe81b3d78e3494f`. The accompanying author report is by Rikiya Takehi, Jayden Teoh, Alex Zhang, and Omar Khattab; see the [retained source attribution](../../artifacts/research/original-source-repeat/README.md), [acquisition record](../../artifacts/research/original-source-repeat/acquisition.json), and upstream [LICENSE](../../artifacts/research/original-source-repeat/source/LICENSE). The upstream logs, data, and networks retain their CC BY 4.0 terms and source ownership; this project's MIT license does not relicense those source materials or adapted actor values.

These adaptations retain the actor alone, transpose the source input/output matrices into the framework's coordinate convention, lift exact float32 values into binary64 for the full-precision serialization, capture the released rounded decimal values separately, and canonicalize signed zero. The [protocol](../../experiments/research/original-source-repeat/protocol.json), [conversion audit](../../experiments/research/original-source-repeat/conversion-audit.json), and [arithmetic correspondence](../../experiments/research/original-source-repeat/arithmetic-correspondence.json) record the transformation and its bounded checks. Critic values are not included in the converted actor.

The fresh task repetition uses a different requested model and reasoning effort and carries the answer inside a required JSON string, as declared in the protocol. Original training and game reward trajectories were not repeated. This project does not imply source-author endorsement of the conversions, repetition, or framework.
